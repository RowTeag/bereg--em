# Ответы компании в Telegram-группах

Отдельный процесс Node.js 18+. Не использует токен клиентской поддержки. Поиск вопросов по ключевым словам, а не смысловая AI-классификация. Отвечает только в группах из allowedChatIds, на сообщения не старше 5 минут. Пропускает ботов, команды, ссылки и сообщения от имени каналов. Лимиты действуют и в preview. Суточный лимит считается по UTC.

## Настройка

1. Создайте отдельного бота через @BotFather. Добавьте TELEGRAM_GROUP_BOT_TOKEN в корневой .env; не публикуйте токен.
2. Скопируйте config.example.json в config.json. Укажите название компании, ссылку на клиентского бота и согласованные группы (числовые chat ID).
3. Заполните topics только реальными услугами. Например: `{"keywords":["бухгалтер", "бухучет"],"reply":"Наша компания может помочь с бухгалтерским сопровождением в Венгрии."}`. Это пример, а не утверждение об услугах компании. Тексты и ключевые слова можно задать на нужном языке.
4. Администратор добавляет бота в согласованную группу. Для обычных сообщений отключите Privacy Mode в BotFather и повторно добавьте бота либо назначьте администратором. ID группы берётся из входящего Telegram update; ссылка на группу его не заменяет.
5. Из корня проекта выполните `node telegram-groups/worker.js`. Режим preview пишет предполагаемые ответы в `.private/telegram-groups/preview.jsonl`, ничего не отправляя.

В личном чате с этим ботом команда `/start` открывает выбор русского, украинского, английского, венгерского или вьетнамского языка. Выбранный язык сохраняется для пользователя; в группе бот отвечает на выбранном языке, а до выбора использует язык Telegram-профиля, если он поддерживается.
6. Проверьте черновики, затем установите mode в auto и перезапустите процесс для автоматических ответов. Остановка: Ctrl+C. Настройки читаются при запуске.

Состояние и offset сохраняются локально. Запускайте только один экземпляр. После аварийного завершения удалите `.private/telegram-groups/worker.lock` только убедившись, что процесс остановлен. При неопределённом результате отправки повтор отключён: отдельный ответ может потеряться, зато не будет повторной рекламы. Для постоянной работы нужен постоянно включённый сервер и persistent disk. Никакие группы автоматически не подключаются, участники и история чатов не собираются.

Документация: https://core.telegram.org/bots/features#privacy-mode и https://core.telegram.org/bots/api
